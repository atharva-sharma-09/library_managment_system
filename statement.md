PROBLEM STATEMENT
-managning books and students records manually can be time consuming and may lead to errors. It can also become difficult to keep track of which books are available and which books have been issued.
-The purpose of this project is to devlop a simple a library Management system that stores book and student information and manages book issuing and returning through a python program.


SCOPE OF THE PROJECT

-The project covers the basic managemenet of a library, It alloes users to add,view and search for books add and view students isssue and return view issued books and genrate a library report.
-The project also provides basic data persistence by saving library information in atext file and loading it when the program starts
-The system is designed as a basic academic project and does not include advanced features such as online access


TARGET USERS

-librarians: To manage students,book    and students transactions
library staff: To maintain basic library records and check issued books
Students: Indirectly as their records and issued books can be managed through the system


HIGH LEVEL FEATURES

-Add new books with book ID,book name and author
-search for a book using its bookID
-Add and view student records
-Issue books to registered students
-return issued books
-view currently issued books
-view all availabale books
